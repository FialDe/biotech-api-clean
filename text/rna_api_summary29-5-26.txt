and then generates a layout.

Important realization:

========================================
STEM DETECTION
========================================

The detectStems() function was reviewed.

Function:

export function detectStems(pairs){

    if(!pairs.length) return [];

    pairs.sort((a,b)=>a[0]-b[0]);

    let stems = [];
    let current = [pairs[0]];

    for(let i=1;i<pairs.length;i++){

        let prev = pairs[i-1];
        let curr = pairs[i];

        if(
            curr[0] === prev[0] + 1 &&
            curr[1] === prev[1] - 1
        ){
            current.push(curr);
        }
        else{
            stems.push(current);
            current = [curr];
        }
    }

    stems.push(current);

    return stems;
}

Conclusion:

The grouping of consecutive base pairs into stems works correctly.
