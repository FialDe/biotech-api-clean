3. NEW analysis.js FUNCTIONS
============================

Added:

----------------------------------------
dotBracketToPairs(dot)
----------------------------------------

Converts:

    (((....)))

into:

    [
      [0,9],
      [1,8],
      [2,7]
    ]

Implementation:

export function dotBracketToPairs(dot){

    let stack = [];
    let pairs = [];

    for(let i=0;i<dot.length;i++){

        if(dot[i] === "("){

            stack.push(i);

        } else if(dot[i] === ")"){

            let start = stack.pop();

            if(start !== undefined){

                pairs.push([start,i]);
            }
        }
    }

    return pairs;
}


----------------------------------------

4. CURRENT STABLE TOPOLOGY RENDERER
===================================

IMPORTANT:
The experimental vertical stem renderer was removed.

The app now uses the stable curved topology renderer again.

CURRENT STABLE LAYOUT BLOCK:

for(let i=0;i<seq.length;i++){

    let angle =
        Math.PI * 0.2 +
        (i / Math.max(seq.length-1,1))
        * Math.PI * 1.6;

    let x =
        centerX +
        Math.cos(angle) * radius * 1.15;

    let y =
        centerY +
        Math.sin(angle) * radius * 0.68;

    // STEM CLUSTERING

    pairs.forEach(pair => {

        let a = pair[0];
        let b = pair[1];

        if(i === a || i === b){

            let partner =
                (i === a) ? b : a;

            let partnerAngle =
                Math.PI * 0.2 +
                (partner / Math.max(seq.length-1,1))
                * Math.PI * 1.6;

            x +=
                Math.cos(partnerAngle) * 18;

            y +=
                Math.sin(partnerAngle) * 12;
        }
    });

    points.push({x,y});
}

This is currently the safest and most stable renderer.


5. IMPORTANT CONCEPTUAL CHANGES
===============================

DOT-BRACKET NOTATION
--------------------

Each character represents one nucleotide.

Example:

Sequence:
    GGGAAAUCCC

Dot-bracket:
    (((....)))

Meaning:

    ( = paired nucleotide
    ) = paired nucleotide
    . = unpaired nucleotide

Pair mapping:

    0 ↔ 9
    1 ↔ 8
    2 ↔ 7


STEMS
-----

A stem is:
- a consecutive region of paired bases

Example:

G ↔ C
G ↔ C
G ↔ C

This forms one stem.


HAIRPIN
-------

A hairpin consists of:
- stem
- loop

Visual idea:

| |
| |
| |
 \_/
